Camera RAW,
decoded in a flash.

FlashRaw is a fast, memory-safe decoder for ~40 camera RAW formats, from Rust, C, C++, Python, the GPU, or this page. Open a file: it is decoded here, in WebAssembly, and never leaves your device.

Nothing is uploaded. The decoder (≈620 KiB) loads in the background once the page is idle. The sample is a 7.6 MB C-RAW CR3 from a Canon EOS R5 Mark II, from raw.pixls.us (CC0).

        01
        
Why FlashRaw

        
One decoder for every camera, built to be fast on every core and safe on every file.

      

      

        

          
Speed

          
    
            
  • Every decoder is multithreaded, even single-stream codecs (lossless JPEG, Nikon, Pentax, Hasselblad, Panasonic v8, Sony ARW1), by speculative parallel decoding
    • 
            
  • Explicit SIMD: SSE4.1, AVX2, AVX-512, NEON and WASM SIMD128, picked at run time
    • 
            
  • Fused single-pass RAW → RGB on the CPU or the GPU
    • 
            
  • Region and tile decodes, zero-copy embedded previews
    • 
          

        

        

          
Security

          
    
            
  • Memory-safe Rust: parsers of untrusted files cannot overflow buffers or use freed memory
    • 
            
  • Bounds-checked parsing, checked offset arithmetic, IFD loop and depth tracking
    • 
            
  • Allocation limits checked before allocating
    • 
            
  • 10 fuzz targets on every PR and nightly; an explicit truncation policy, never silent garbage
    • 
          

        

        

          
Support

          
    
            
  • ~40 RAW formats, every make and model on raw.pixls.us, each checked against pinned output hashes
    • 
            
  • CR3 incl. C-RAW, JPEG XL DNG, lossy and deflate DNG, GoPro GPR, Sigma X3F, Fuji compressed, Panasonic v4–v8, IIQ, 3FR/FFF
    • 
            
  • 1,000+ models in the built-in camera database
    • 
          

        

      

      

        

          
Bindings

          
Rust, C, C++, Python (NumPy, zero-copy, GIL released) and JavaScript/TypeScript, plus a compatibility C API for porting existing RAW code.

        

        

          
GPU

          
Unpack, demosaic, white balance and colour as WGSL compute shaders: Metal, Vulkan, DX12 and WebGPU. Results can stay on the GPU.

        

        

          
Browser

          
One npm package for browsers, Web Workers, Node.js and Deno. WASM SIMD, multithreaded when cross-origin isolated, optional WebGPU.

Install

        
The same decoder, from every language.

      

      

        

          
          
          
          
        

        

          
npm install flashraw

          
import { FlashRaw } from 'flashraw';

const raw = await FlashRaw.open(file);          // File, Blob, ArrayBuffer, Uint8Array
console.log(raw.metadata.camera.name, raw.metadata.exposure.iso);

const preview = await raw.preview();            // embedded JPEG, no decoding
const img = await raw.decode({ output: 'rgba8' });
ctx.putImageData(img.toImageData(), 0, 0);
raw.close();

          
Browsers, Web Workers, Node.js ≥ 18 and Deno. Vite, webpack, Rollup and esbuild. npm README · WASM internals

        

        

          
cargo add flashraw

          
use flashraw::{FlashRaw, DecodeOptions, OutputFormat};

let raw = FlashRaw::open_path("photo.NEF")?;     // memory-mapped, headers only
let m = raw.metadata();
println!("{} {}x{} ISO {:?}", m.camera(), m.width, m.height, m.exposure.iso);

let rgba = raw.decode(DecodeOptions { output: OutputFormat::Rgba8, ..Default::default() })?;

          
Features: rayon, simd, mmap (default), gpu, jpegxl, serde. MSRV 1.85.

        

        

          
pip install flashraw

          
import flashraw

with flashraw.open("photo.NEF") as raw:
    print(raw.metadata.camera.name, raw.metadata.exposure.iso)
    sensor = raw.decode().array                 # numpy uint16 (h, w), zero-copy
    rgba = raw.decode(output="rgba8").array     # numpy uint8 (h, w, 4)

          
Decoding releases the GIL, so Python threads decode files in parallel. Python docs

        

        

          
cargo build --release -p flashraw-capi   # or CMake: find_package(flashraw)

          
#include <flashraw.h>

flashraw_file *f = NULL;
if (flashraw_open_path("photo.NEF", NULL, &f) != FLASHRAW_OK) return 1;
flashraw_decode_options o;
flashraw_decode_options_init(&o);
o.output = FLASHRAW_OUTPUT_RGBA8;
flashraw_frame *fr = NULL;
if (flashraw_decode(f, &o, &fr) == FLASHRAW_OK) {
    const uint8_t *rgba = flashraw_frame_data(fr);  /* width x height x 4 */
    flashraw_frame_free(fr);
}
flashraw_file_free(f);
