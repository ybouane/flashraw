# flashraw-capi

Stable C ABI for [FlashRaw](../../README.md), plus a header-only C++17 wrapper.

- `include/flashraw.h` — the C header (generated by cbindgen from this crate, checked in)
- `include/flashraw.hpp` — C++17 RAII wrapper: `flashraw::file`, `flashraw::frame`,
  exceptions per error kind, span views over the samples
- `libflashraw_capi.{so,dylib,a}` / `flashraw_capi.{dll,lib}` — built by
  `cargo build --release -p flashraw-capi`
- `CMakeLists.txt` — builds with cargo and installs libraries, headers, `flashraw.pc` and a
  `find_package(flashraw)` package

```c
flashraw_file *f;
flashraw_open_path("photo.ARW", NULL, &f);
flashraw_decode_options o;
flashraw_decode_options_init(&o);
o.output = FLASHRAW_OUTPUT_RGBA8;
flashraw_frame *img;
flashraw_decode(f, &o, &img);
/* flashraw_frame_data(img): width * height * 4 bytes */
flashraw_frame_free(img);
flashraw_file_free(f);
```

Usage, linking, memory ownership, threading and the ABI stability policy:
[docs/c-api.md](../../docs/c-api.md). Examples: [`examples/c`](../../examples/c),
[`examples/cpp`](../../examples/cpp).

Regenerate the header after changing the exported API:

```sh
cbindgen --config crates/flashraw-capi/cbindgen.toml --crate flashraw-capi \
         --output crates/flashraw-capi/include/flashraw.h
```
